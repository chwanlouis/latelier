# L'atelier Frontend (React)

React + Vite frontend that recreates the POC experience from `backend/template`.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Implemented POC parity

- Dark GitBook-style layout with left navigation
- Introduction content view with cards and figures
- Recipe view with searchable autocomplete input and keyboard navigation
- Shared static assets served from `public/template`
